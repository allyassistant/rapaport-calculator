# 💎 Rapaport Calculator

Rapaport 價格計算器 - 鑽石價格快速計算工具

## 使用連結
https://allyassistant.github.io/rapaport-calculator/

## 功能
- 支援 RBC (Round) 同 Pear (其他形狀) 兩種表格
- 自動根據重量選擇正確價格區間
- 支援 D-M 顏色同 FL-SI2 淨度
- 自動計算 Discount
- 即時顯示價格報價
- **每週五自動更新** Rapaport 最新價格

## 使用方法
1. 選擇 Shape (RBC = 圓鑽, Pear = 其他形狀)
2. 輸入 Carat 重量
3. 選擇 Color 同 Clarity
4. 輸入 Discount (預設 -30)
5. 按 Calculate Price 計算

## 自動化
價格數據每週五 12:00 HKT 自動從 Rapaport API 更新。
